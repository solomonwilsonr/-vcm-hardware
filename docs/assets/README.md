# README media

These assets are bundled locally so the README does not depend on an external image host.

- `logo.svg`: the existing VCM brand mark, copied from `site/logo.svg`.
- `dashboard-compare.jpg`: the existing dashboard capture from `docs/video/real-site/compare.jpg`.
- `landing-page.jpg`: the existing homepage capture from `docs/video/real-site/hero.jpg`.
- `vcm-tour.gif`: the first 18 seconds of `docs/video/vcm-promo-20s.mp4`, reduced to 800 px wide,
  6 frames/second and a 96-color palette (about 3.6 MiB).

The GIF uses page captures with editorial camera motion. Only the comparison scene shows the
running dashboard; the dependency and fleet scenes are landing-page illustrations. The images
show an earlier captured demo state, not continuously refreshed data. The dashboard capture
includes observations attached to the baseline, which add findings beyond the plain manifest diff.

## Regenerate the GIF

The original video and capture sources are local production assets, not bundled with this
README update. If you have the source video and FFmpeg installed, run from the repository
root (add `-y` to overwrite an existing GIF):

```bash
ffmpeg -i docs/video/vcm-promo-20s.mp4 -t 18 \
  -vf 'fps=6,scale=800:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=96[p];[s1][p]paletteuse=dither=bayer:bayer_scale=3' \
  -loop 0 docs/assets/vcm-tour.gif
```

The local source video was generated by `docs/video/build_promo_real.py`. Updating the
screenshots or logo also requires refreshing the copies here. Keep readable screenshots
alongside the GIF for readers who prefer a static view.
